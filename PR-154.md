## What changed

- **Shared design token system**: Added comprehensive `:root` design tokens in `src/web/static/base.css` covering palette, semantic feedback states (success, warning, danger, info), typography, spacing scale, border widths, shadows, radii, control heights, and focus rings.
- **Reusable component primitives**: Implemented shared styles for `.card`, `.table-wrap`/`table.table`, `.badge`, `.alert`, and form controls.
- **Control sizing contract preservation**: Decoupled single-line controls (`input`, `select`, `.input`, `.select`) from textareas (`textarea`, `.textarea`). Single-line controls have `min-height: var(--control-height)` (42px) on desktop and expand to 44px on mobile (`<= 640px`) with 16px font-size for touch and iOS zoom compliance. Textareas consistently preserve 96px minimum height (`min-height: 96px; resize: vertical;`) on both desktop and mobile, eliminating previous subclass height collapse.
- **Semantic badge cascade isolation**: Scoped `order.css` `.badge` neutral styling using `:not([class*="badge--"])` and elevated semantic variant selectors to compound `.badge.badge--*` in `base.css`. All 4 supported variants (`success`, `warning`, `danger`, and `info`) retain their intended semantic colors and backgrounds across stylesheets.
- **Comprehensive verification**: Updated `tests/test_ui_styling.py` with cascade requirement evaluations and added headless browser computed style verifications in `tests/verify_ui_rendering.mjs`.

## How to test it

1. Run the UI styling regression test suite:

   ```bash
   python -m pytest tests/test_ui_styling.py -v
   ```

2. Run real browser rendering verification (desktop 1280px and mobile 390px):

   ```bash
   node tests/verify_ui_rendering.mjs
   ```

3. Run full test suite:

   ```bash
   python -m pytest -q
   ```

4. Run lint and whitespace checks:

   ```bash
   ruff check src tests/test_ui_styling.py
   git diff --check
   ```

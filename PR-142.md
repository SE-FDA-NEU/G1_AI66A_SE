## What changed

The seller analytics API now returns daily, weekly, or monthly seller-scoped
financial time series using the canonical inclusive `from` and `to` filters.
Each period reports `gross_order_value`, `completed_revenue`,
`pending_escrow_revenue`, and `cancellation_rate` as a percentage from 0 to
100. All metrics use the same effective timestamp (`completed_at`, falling
back to `created_at`), cancelled orders are excluded from pending escrow, and
the API documents the new grouping and error contract.

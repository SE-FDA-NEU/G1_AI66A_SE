# Firebase Hosting deployment

## Scope

The Firebase project is `mini-marketplace-se`. Hosting contains only the
browser frontend exported from `src/web/pages` and `src/web/static`. Backend
source, `.env` files, SQLite databases and development-only files are not
copied into `public/`.

The expected default Hosting URL is:

`https://mini-marketplace-se.web.app`

The URL is available after Hosting has been enabled and the first deployment
has completed. A preview URL is generated by the Firebase CLI for each preview
channel and is not known until that command runs.

## Prerequisites

Install the Firebase CLI, authenticate with an account that has access to the
project, and run commands from the repository root:

```powershell
npm install -g firebase-tools
firebase login
firebase use mini-marketplace-se
```

If Hosting has not been registered for the project, create the default site
once in the Firebase Console, or run `firebase hosting:sites:create
mini-marketplace-se` when the site ID is available. Do not create a second
site for the same deployment unless the team explicitly chooses a different
site ID.

## Export and inspect

The export is intentionally an allow-list and starts from a clean directory:

```powershell
python scripts/export_frontend.py
Get-ChildItem -Recurse public | Select-Object FullName
```

The generated directory should contain only the exported HTML pages,
`404.html`, and files under `static/`. In particular, it must not contain
`src/`, `tests/`, `.env`, `*.db`, or backend Python files. `public/` is ignored
because it is reproducible build output.

## Preview deployment

```powershell
python scripts/export_frontend.py
firebase hosting:channel:deploy preview
```

The CLI prints the preview URL. Record that URL in the issue/PR and verify
`/products`, `/products/P-100`, `/orders/1`, `/login`, `/cart`, `/checkout`,
`/notifications`, `/seller/orders`, and `/admin` by opening each URL directly
and refreshing it. Test at desktop and mobile viewport sizes. An unknown URL,
for example `/does-not-exist`, must show the custom 404 page.

## Production deployment

After human review of the preview and the generated file list:

```powershell
python scripts/export_frontend.py
firebase deploy --only hosting
```

The production URL is normally `https://mini-marketplace-se.web.app` (and the
Firebase-provided `firebaseapp.com` alias). Record the actual URL and
screenshots as verification evidence; this repository does not claim a deploy
or browser review that has not been performed.

## API dependency

The pages use relative `/api/v1/...` requests because the existing application
serves frontend and API from one origin locally. Firebase Hosting serves the
static pages only. To make authenticated data operations work in a hosted
preview, the backend tunnel must expose the API under the same public origin
or a separately agreed Hosting rewrite must be added after the tunnel URL and
security policy are known. No tunnel URL, credential, or secret is committed
here.
